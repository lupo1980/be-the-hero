The Be The Hero project is a full-stack application built during Rocketseat's Semana OmniStack 11.0 designed to 
connect non-governmental organizations (NGOs) with everyday people ("heroes") willing to fund specific charitable cases.

How It WorksFor NGOs: Organizations log into a web dashboard to register, manage, and publish specific cases or 
incidents that require financial assistance (including a title, description, and target monetary amount).

For Users ("Heroes"): Contributors browse available cases through a mobile application and can directly contact the respective NGO 
via WhatsApp or email to provide support.

Tech Stack
Back-End: Node.js with Express and Knex.js for database management.
Front-End (Web): React.Mobile App: React Native with Expo
